# 🛍️ Nostra - E-commerce Website (HTML, CSS, JavaScript)

## 🌟 Overview

Nostra is a fully responsive, front-end E-commerce website built as an assignment to demonstrate proficiency in core web development technologies: HTML, CSS, and JavaScript.

The website features a multi-page layout and implements dynamic client-side functionality for searching and filtering products on the collections page.

## ✨ Features

  * Multi-Page Structure: Includes Home, Collections, Contact Us, and a Login page.
  * Fully Responsive Design: Adapts smoothly to various screen sizes (desktop, tablet, mobile).
  * Dynamic Search: Allows users to search products by name on the Collections page using JavaScript.
  * Client-side Filtering: Enables filtering of products by category (e.g., Men's Wear, Women's Wear) using JavaScript.
  * Sticky Footer: The footer remains consistently at the bottom of the viewport using Flexbox for clean layout integrity.


## 🛠️ Technologies Used

HTML - Project structure and semantic content. 
CSS - Styling, responsiveness (Media Queries), and layout (Flexbox).
JavaScript - Implementing search and filter logic (`script.js`).
Font Awesome - Icons used in the navigation bar and elsewhere.
